Створення форм в HTML — це основа для збору даних від користувачів (реєстрація, пошукові запити, зворотний зв'язок тощо).

Ось базовий путівник по синтаксису та простий приклад.

## 🔑 Базові елементи форми

Усі форми будуються за допомогою кількох основних тегів:

- **`<form>`** — головний контейнер для всієї форми. Він має два важливі атрибути:
    
    - `action` — URL-адреса, куди відправляються дані (наприклад, на серверний скрипт).
        
    - `method` — метод відправки даних (найчастіше `GET` або `POST`).
        
- **`<label>`** — текстова мітка (підпис) для поля введення. Покращує доступність (accessibility). Атрибут `for` має збігатися з `id` відповідного інпуту.
    
- **`<input>`** — універсальний елемент для введення даних. Його тип визначається атрибутом `type` (наприклад, `text`, `email`, `password`, `submit`).
    
- **`name`** — **найважливіший атрибут** для будь-якого інпуту. Саме під цим іменем сервер отримає введене значення (наприклад, `name="username"`).
    

## 📝 Простий приклад форми

Ось приклад базової форми реєстрації чи підписки, де користувач вводить ім'я, email та натискає кнопку відправки:

HTML

```
<form action="/submit-form-endpoint" method="POST">
  
  <div>
    <label for="userName">Ім'я:</label>
    <input type="text" id="userName" name="username" placeholder="Введіть ваше ім'я" required>
  </div>

  <br>

  <div>
    <label for="userEmail">Електронна пошта:</label>
    <input type="email" id="userEmail" name="email" placeholder="example@mail.com" required>
  </div>

  <br>

  <div>
    <input type="submit" value="Надіслати">
  </div>

</form>
```

## 💡 Що варто взяти до уваги:

1. **`required`** — додавання цього атрибута (як у прикладі вище) робить поле обов'язковим для заповнення. Браузер сам покаже попередження, якщо користувач спробує відправити порожню форму.
    
2. **`placeholder`** — сірий підказковий текст всередині поля, який зникає, коли користувач починає писати.
    
3. **Групування (`<div>` або `<br>`)** — HTML-елементи форми за замовчуванням є рядковими (`inline`), тому їх варто обгортати в блочні елементи або розділяти, щоб вони вишикувалися один під одним.

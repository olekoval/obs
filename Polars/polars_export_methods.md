# Таблиця 5.5. Методи експорту

*Джерело: «Python Polars: подробное руководство», с. 125.*

| Метод | Опис |
|---|---|
| `.to_arrow()` | Збирає базові масиви Arrow датафрейму в таблицю Arrow |
| `.to_dict()` | Перетворює датафрейм на словник, ключами якого є імена об'єктів Series, а значеннями — їхній вміст |
| `.to_dicts()` | Перетворює кожен рядок датафрейму на словник Python |
| `.to_init_repr()` | Перетворює датафрейм на рядкове представлення |
| `.to_jax()` | Перетворює датафрейм на масив JAX або словник масивів JAX |
| `.to_numpy()` | Перетворює датафрейм на масив NumPy |
| `.to_pandas()` | Перетворює датафрейм на датафрейм pandas |
| `.to_struct()` | Перетворює датафрейм на об'єкт Series зі значеннями типу Struct |
| `.to_torch()` | Перетворює датафрейм на тензор PyTorch, набір або словник тензорів |

## Примітка

Крім перелічених, і датафрейми, і лінива версія мають метод `serialize()`, який також можна віднести до методів експорту. Решта методів експорту доступні лише для звичайних датафреймів, оскільки ліниві датафрейми не містять даних.

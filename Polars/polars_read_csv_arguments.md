# Таблиця 6.2. Часто використовувані аргументи функції `pl.read_csv()`

*Джерело: «Python Polars: подробное руководство», с. 135 (с. 136 у PDF).*

| Аргумент | Опис |
|---|---|
| `source` | Шлях до файлу або об'єкта |
| `has_header` | Індикатор того, чи містить перший рядок файлу заголовки стовпців |
| `columns` | Стовпці для вибору. Приймає список індексів стовпців (починаючи з нуля) або імен стовпців |
| `separator` | Однобайтовий символ, що використовується як роздільник у файлі |
| `skip_rows` | Пропуск певної кількості рядків |
| `null_values` | Значення, які необхідно інтерпретувати як пропущені |
| `encoding` | Кодування. Значення за замовчуванням — `utf8`. Значення `utf8-lossy` означає заміну невідомих символів на спеціальний символ �. При використанні кодувань, відмінних від `utf8` і `utf8-lossy`, вхідні дані спочатку декодуються в пам'яті засобами Python |

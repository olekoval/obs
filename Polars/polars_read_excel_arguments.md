# Таблиця 6.3. Часто використовувані аргументи функції `pl.read_excel()`

*Джерело: «Python Polars: подробное руководство», с. 140 (с. 141 у PDF).*

| Аргумент | Опис |
|---|---|
| `source` | Шлях до файлу або об'єкта |
| `sheet_id` | Номер аркуша для імпорту (0 — для всіх аркушів). Якщо не задано цей параметр і параметр `sheet_name`, за замовчуванням використовується значення 1. При виборі кількох аркушів функція поверне словник, де ключами є імена аркушів, а значеннями — датафрейми |
| `sheet_name` | Ім'я аркуша для завантаження. Не може використовуватися разом з аргументом `sheet_id` |
| `engine` | Пакет, що використовується для обробки файлу Excel. Може приймати значення `calamine`, `xlsx2csv` або `openpyxl` |
| `engine_options` | Додаткові опції, що передаються конструктору рушія (не використовується з рушієм `calamine`) |
| `read_options` | Додаткові опції, що передаються функції читання файлу рушія (не використовується з рушієм `openpyxl`) |
| `has_header` | Індикатор наявності заголовків у файлі |

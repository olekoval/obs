# Методи агрегації датафрейму Polars

| Метод | Опис | Приклад застосування |
|---|---|---|
| `.count()` | Повертає датафрейм з одного рядка: кількість **не-null** значень у кожному стовпці | `df.count()` → `a=4, b=3` |
| `.max()` | Повертає датафрейм з одного рядка: максимальне значення кожного стовпця | `df.max()` → `a=4, b=40.0` |
| `.max_horizontal()` | Повертає `Series` з максимумом по кожному рядку (по горизонталі, між стовпцями); `null` ігноруються | `df.max_horizontal()` → `Series "max": [10.0, 20.0, 3.0, 40.0]` |
| `.mean()` | Повертає датафрейм з одного рядка: середнє арифметичне кожного стовпця (`null` ігноруються) | `df.mean()` → `a=2.5, b=23.333333` |
| `.mean_horizontal()` | Повертає `Series` із середнім арифметичним по кожному рядку; `null` ігноруються | `df.mean_horizontal()` → `Series "mean": [5.5, 11.0, 3.0, 22.0]` |
| `.median()` | Повертає датафрейм з одного рядка: медіану кожного стовпця | `df.median()` → `a=2.5, b=20.0` |
| `.min()` | Повертає датафрейм з одного рядка: мінімальне значення кожного стовпця | `df.min()` → `a=1, b=10.0` |
| `.min_horizontal()` | Повертає `Series` з мінімумом по кожному рядку; `null` ігноруються | `df.min_horizontal()` → `Series "min": [1.0, 2.0, 3.0, 4.0]` |
| `.product()` | Повертає датафрейм з одного рядка: добуток значень кожного стовпця (`null` ігноруються) | `df.product()` → `a=24, b=8000.0` |
| `.quantile()` | Повертає датафрейм з одного рядка: квантиль кожного стовпця. Аргументи: `quantile` (від 0 до 1) та `interpolation` (`"nearest"` за замовчуванням, `"linear"`, `"lower"`, `"higher"`, `"midpoint"`) | `df.quantile(0.25, interpolation="linear")` → `a=1.75, b=15.0` |
| `.std()` | Повертає датафрейм з одного рядка: стандартне відхилення кожного стовпця; параметр `ddof=1` за замовчуванням (вибіркове відхилення) | `df.std()` → `a=1.290994, b=15.275252` |
| `.sum()` | Повертає датафрейм з одного рядка: суму значень кожного стовпця (`null` ігноруються) | `df.sum()` → `a=10, b=70.0` |
| `.sum_horizontal()` | Повертає `Series` із сумою по кожному рядку; `null` ігноруються | `df.sum_horizontal()` → `Series "sum": [11.0, 22.0, 3.0, 44.0]` |
| `.var()` | Повертає датафрейм з одного рядка: дисперсію кожного стовпця; параметр `ddof=1` за замовчуванням | `df.var()` → `a=1.666667, b=233.333333` |

## Датафрейм для прикладів

```python
import polars as pl

df = pl.DataFrame({
    "a": [1, 2, 3, 4],
    "b": [10.0, 20.0, None, 40.0],
})
```

## Примітки

- Методи без суфікса `_horizontal` агрегують **по стовпцях** і повертають датафрейм з одного рядка.
- Методи із суфіксом `_horizontal` агрегують **по рядках** і повертають `Series` довжиною, що дорівнює кількості рядків датафрейму.
- Горизонтальні методи працюють зі стовпцями, які можна привести до спільного типу. Тут `a` (`Int64`) і `b` (`Float64`) приводяться до `Float64`.
- Для змінення поведінки `std()` і `var()` на «генеральну» використовуйте `ddof=0`.
- Точний вигляд виводу та доступність окремих методів (наприклад, `DataFrame.count()`) можуть відрізнятися залежно від версії Polars.

# Таблиця 6.1. Підтримувані Polars формати введення/виведення та відповідні їм функції читання і методи запису

*Джерело: «Python Polars: подробное руководство», с. 133 (с. 134 у PDF).*

Для стислості префікси `pl.` і `df.` у таблиці не завжди вказано. Імена, що починаються з `read_` і `scan_`, належать функціям верхнього рівня Polars, а імена, що починаються з `write_` і `sink_`, вказують на методи звичайних і лінивих датафреймів.

| Формат | Читання (pl.) | Читання в лінивому режимі (pl.) | Запис (df.) | Запис у потоковому режимі (df.) |
|---|---|---|---|---|
| Avro | `pl.read_avro()` | | `write_avro()` | |
| Буфер обміну | `pl.read_clipboard()` | | `write_clipboard()` | |
| CSV | `pl.read_csv()`<br>`pl.read_csv_batched()` | `pl.scan_csv()` | `write_csv()` | `sink_csv()` |
| Бази даних | `pl.read_database()`<br>`pl.read_database_uri()` | | `write_database()` | |
| Delta Lake | `pl.read_delta()` | `pl.scan_delta()` | `write_delta()` | |
| Excel/ODS | `pl.read_excel()`<br>`pl.read_ods()` | | `write_excel()` | |
| Feather/IPC | `pl.read_ipc()`<br>`pl.read_ipc_schema()`<br>`pl.read_ipc_stream()` | `pl.scan_ipc()` | `write_ipc()`<br>`write_ipc_stream()` | `sink_ipc()` |
| Iceberg | | `pl.scan_iceberg()` | | |
| JSON | `pl.read_json()`<br>`pl.read_ndjson()` | `pl.scan_ndjson()` | `write_json()`<br>`write_ndjson()` | `sink_ndjson()` |
| Parquet | `pl.read_parquet()`<br>`pl.read_parquet_schema()` | `pl.scan_parquet()` | `write_parquet()` | `sink_parquet()` |
| Набори даних PyArrow¹ | | `pl.scan_pyarrow_dataset()` | | |

¹ Фактично це не формат файлу. Polars може використовувати рушій PyArrow для розбору даних, що відповідають формату, який може прочитати `pyarrow`.

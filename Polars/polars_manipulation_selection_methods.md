# Таблиця 5.6. Методи маніпуляції та відбору даних

*Джерело: «Python Polars: подробное руководство», сс. 125–127. Описи складено на основі документації Polars.*

| Метод | Опис |
|---|---|
| `.bottom_k()` | Повертає `k` рядків із найменшими значеннями у вказаному стовпці (або стовпцях) |
| `.cast()` | Приводить стовпці до вказаних типів даних |
| `.clear()` | Повертає порожній датафрейм із тією самою схемою (за потреби — з `n` рядками, заповненими `null`) |
| `.clone()` | Створює копію датафрейму; дані фактично не копіюються, тож операція дешева |
| `.drop()` | Видаляє вказані стовпці та повертає новий датафрейм |
| `.drop_in_place()` | Видаляє стовпець безпосередньо в наявному датафреймі та повертає його як `Series` |
| `.drop_nulls()` | Видаляє рядки, що містять `null` (в усіх або лише у вказаних стовпцях) |
| `.explode()` | Розгортає стовпці зі списками: кожен елемент списку стає окремим рядком |
| `.extend()` | Дописує рядки іншого датафрейму з такою самою схемою в кінець наявного, змінюючи його на місці |
| `.fill_nan()` | Замінює значення `NaN` на вказане значення |
| `.fill_null()` | Замінює `null` на вказане значення або за стратегією (`forward`, `backward`, `min`, `max`, `mean`, `zero`, `one`) |
| `.filter()` | Залишає лише рядки, що задовольняють задану умову (предикат) |
| `.first()` | Повертає перший рядок у вигляді датафрейму з одним рядком |
| `.gather_every()` | Повертає кожен `n`-й рядок, за потреби зі зміщенням `offset` |
| `.get_column()` | Повертає стовпець за назвою як `Series` |
| `.get_column_index()` | Повертає позицію (індекс) стовпця за його назвою |
| `.get_columns()` | Повертає всі стовпці датафрейму у вигляді списку об'єктів `Series` |
| `.group_by()` | Групує рядки за значеннями вказаних стовпців; до результату застосовують агрегації |
| `.group_by_dynamic()` | Групує рядки за динамічними часовими (або цілочисельними) вікнами на основі індексного стовпця |
| `.head()` | Повертає перші `n` рядків (за замовчуванням 5) |
| `.hstack()` | Додає стовпці праворуч (горизонтальне об'єднання) і повертає новий датафрейм |
| `.insert_column()` | Вставляє `Series` як новий стовпець на вказану позицію, змінюючи датафрейм на місці |
| `.inspect()` | Виводить поточний стан датафрейму на цьому кроці плану (для налагодження) і повертає його без змін |
| `.interpolate()` | Заповнює пропущені значення в числових стовпцях лінійною інтерполяцією |
| `.item()` | Повертає одне значення: з датафрейму 1×1 або з клітинки за вказаними рядком і стовпцем |
| `.iter_columns()` | Повертає ітератор по стовпцях як `Series` |
| `.iter_rows()` | Повертає ітератор по рядках у вигляді кортежів (або словників при `named=True`) |
| `.iter_slices()` | Повертає ітератор по частинах датафрейму (зрізах) заданого розміру в рядках |
| `.join()` | З'єднує датафрейм з іншим за ключовими стовпцями (`inner`, `left`, `right`, `full`, `semi`, `anti`, `cross`) |
| `.join_asof()` | Наближене з'єднання: для кожного рядка підбирається найближчий за ключем рядок іншого датафрейму (зазвичай для відсортованих часових даних) |
| `.join_where()` | З'єднує датафрейми за довільними умовами (зокрема нерівностями), а не лише за рівністю ключів |
| `.last()` | Повертає останній рядок у вигляді датафрейму з одним рядком |
| `.limit()` | Повертає перші `n` рядків (за замовчуванням 5); псевдонім `head()` |
| `.melt()` | Перетворює датафрейм із широкого формату на довгий; застарілий псевдонім `unpivot()` |
| `.merge_sorted()` | Зливає два датафрейми, відсортовані за ключем, в один відсортований датафрейм |
| `.partition_by()` | Розбиває датафрейм на список датафреймів за унікальними значеннями вказаних стовпців |
| `.pipe()` | Застосовує до датафрейму задану функцію, що дозволяє будувати зручні ланцюжки викликів |
| `.pivot()` | Перетворює датафрейм із довгого формату на широкий (зведена таблиця) з агрегуванням значень |
| `.rechunk()` | Переносить дані в один неперервний блок пам'яті, що прискорює подальші операції |
| `.rename()` | Перейменовує стовпці за відображенням «стара назва → нова» або за функцією |
| `.replace_column()` | Замінює стовпець на вказаній позиції новим `Series`, змінюючи датафрейм на місці |
| `.reverse()` | Повертає датафрейм із рядками у зворотному порядку |
| `.rolling()` | Групує рядки за ковзним вікном на основі індексного стовпця; до результату застосовують агрегації |
| `.row()` | Повертає один рядок як кортеж за індексом або за умовою |
| `.rows()` | Повертає всі рядки як список кортежів (або словників при `named=True`) |
| `.rows_by_key()` | Групує рядки у словник за значеннями ключового стовпця |
| `.sample()` | Повертає випадкову вибірку рядків за кількістю (`n`) або часткою (`fraction`) |
| `.select()` | Вибирає стовпці або обчислює вирази; результат містить лише їх |
| `.select_seq()` | Те саме, що `select()`, але вирази виконуються послідовно, а не паралельно |
| `.set_sorted()` | Позначає стовпець як відсортований (без перевірки) для оптимізації наступних операцій |
| `.shift()` | Зсуває значення стовпців на `n` позицій, а порожні місця заповнює `null` |
| `.shrink_to_fit()` | Зменшує обсяг пам'яті, виділеної під датафрейм, до фактично потрібного |
| `.slice()` | Повертає зріз рядків за початковим зміщенням і довжиною |
| `.sort()` | Сортує рядки за значеннями одного або кількох стовпців |
| `.sql()` | Виконує SQL-запит до датафрейму (у запиті він доступний під ім'ям `self`) |
| `.tail()` | Повертає останні `n` рядків (за замовчуванням 5) |
| `.to_dummies()` | Перетворює категоріальні стовпці на фіктивні змінні (one-hot encoding) |
| `.to_series()` | Повертає стовпець за його позицією як `Series` (за замовчуванням перший) |
| `.top_k()` | Повертає `k` рядків із найбільшими значеннями у вказаному стовпці (або стовпцях) |
| `.transpose()` | Транспонує датафрейм: рядки стають стовпцями, а стовпці — рядками |
| `.unique()` | Видаляє дублікати рядків (в усіх або лише у вказаних стовпцях) |
| `.unnest()` | Розгортає стовпці типу `Struct` на окремі стовпці за кількістю полів |
| `.unpivot()` | Перетворює датафрейм із широкого формату на довгий (протилежність `pivot()`) |
| `.unstack()` | Розгортає один довгий стовпець у кілька стовпців заданими блоками рядків |
| `.update()` | Оновлює значення датафрейму значеннями з іншого за ключовими стовпцями |
| `.upsample()` | Збільшує частоту часових даних: додає рядки з пропущеними моментами часу через рівні інтервали |
| `.vstack()` | Додає рядки іншого датафрейму знизу (вертикальне об'єднання) і повертає новий датафрейм |
| `.with_columns()` | Додає нові стовпці або замінює наявні, зберігаючи решту стовпців |
| `.with_columns_seq()` | Те саме, що `with_columns()`, але вирази виконуються послідовно, а не паралельно |
| `.with_context()` | Додає до контексту схему інших лінивих датафреймів, щоб вирази могли звертатися до їхніх стовпців |
| `.with_row_count()` | Додає стовпець із номерами рядків; застарілий метод, замінений `with_row_index()` |
| `.with_row_index()` | Додає на початок стовпець із індексами рядків (за замовчуванням `index`, з нуля) |

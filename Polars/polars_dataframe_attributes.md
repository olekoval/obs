# Атрибути датафрейму Polars

| Атрибут | Опис | Приклад застосування |
|---|---|---|
| `.columns` | Повертає список назв стовпців датафрейму (`list[str]`) | `df.columns` → `['name', 'age', 'city']` |
| `.dtypes` | Повертає список типів даних усіх стовпців у тому ж порядку, що й стовпці (`list[DataType]`) | `df.dtypes` → `[String, Int64, String]` |
| `.flags` | Повертає словник, де ключ — назва стовпця, а значення — словник прапорців (`SORTED_ASC`, `SORTED_DESC`, `FAST_EXPLODE`) з булевими значеннями; показує, чи відомо Polars, що стовпець відсортований тощо (`dict[str, dict[str, bool]]`) | `df.sort("age").flags` → `{'name': {'SORTED_ASC': False, 'SORTED_DESC': False}, 'age': {'SORTED_ASC': True, 'SORTED_DESC': False}, ...}` |
| `.height` | Повертає кількість рядків у датафреймі (`int`) | `df.height` → `3` |
| `.schema` | Повертає впорядковану схему: відображення «назва стовпця → тип даних» (`Schema`, подібна до `OrderedDict`) | `df.schema` → `Schema({'name': String, 'age': Int64, 'city': String})` |
| `.shape` | Повертає кортеж із розмірністю датафрейму: (кількість рядків, кількість стовпців) (`tuple[int, int]`) | `df.shape` → `(3, 3)` |
| `.width` | Повертає кількість стовпців у датафреймі (`int`) | `df.width` → `3` |

## Датафрейм для прикладів

```python
import polars as pl

df = pl.DataFrame({
    "name": ["Олена", "Іван", "Марія"],
    "age": [28, 35, 22],
    "city": ["Київ", "Львів", "Одеса"],
})
```

## Примітка

`.flags` повертає прапорці лише для внутрішньої оптимізації; значення `SORTED_ASC` стає `True` після виклику `sort()` або `set_sorted()`. Точний вигляд виводу може дещо відрізнятися залежно від версії Polars.

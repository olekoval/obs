# Таблиця 5.7. Прочі методи

*Джерело: «Python Polars: подробное руководство», с. 127. Описи складено на основі документації Polars.*

Методи, що не ввійшли до жодної з попередніх категорій.

| Метод | Опис |
|---|---|
| `.cache()` | Кешує проміжний результат у плані запиту, щоб при повторному використанні в тому ж запиті він не обчислювався заново |
| `.collect()` | Виконує побудований план лінивого запиту і повертає результат як звичайний датафрейм у пам'яті |
| `.collect_async()` | Асинхронно виконує план лінивого запиту, не блокуючи потік; замість датафрейму повертає об'єкт, на який можна очікувати (`await`) |
| `.collect_schema()` | Повертає схему (назви стовпців і їхні типи), не виконуючи сам запит |
| `.corr()` | Обчислює матрицю кореляції (за замовчуванням Пірсона) між числовими стовпцями |
| `.equals()` | Перевіряє, чи два датафрейми збігаються за вмістом (значеннями, схемою та порядком стовпців) |
| `.lazy()` | Перетворює датафрейм на лінивий, не виконуючи жодних обчислень; для лінивого датафрейму повертає його самого |
| `.map_batches()` | Застосовує користувацьку функцію до всього датафрейму як до одного блоку даних (пакета) |
| `.map_rows()` | Застосовує користувацьку функцію до кожного рядка (у вигляді кортежу) і повертає новий датафрейм; працює повільно, тому краще використовувати вирази |
| `.pipe()` | Передає датафрейм у вказану функцію, що дозволяє будувати зручні ланцюжки викликів |
| `.profile()` | Виконує запит і повертає результат разом із датафреймом, що містить час виконання кожного вузла плану |

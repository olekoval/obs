# Таблиця 5.7. Прочі методи

*Джерело: «Python Polars: подробное руководство», с. 127.*

Методи, що не ввійшли до жодної з попередніх категорій. Позначка ✓ означає, що метод доступний у відповідному типі датафрейму, «—» — недоступний.

| Метод | Датафрейм | Лінивий датафрейм |
|---|:---:|:---:|
| `.cache()` | — | ✓ |
| `.collect()` | — | ✓ |
| `.collect_async()` | — | ✓ |
| `.collect_schema()` | ✓ | ✓ |
| `.corr()` | ✓ | — |
| `.equals()` | ✓ | — |
| `.lazy()` | ✓ | ✓ |
| `.map_batches()` | — | ✓ |
| `.map_rows()` | ✓ | — |
| `.pipe()` | — | ✓ |
| `.profile()` | — | ✓ |

## Примітка

Метод `.pipe()` тут позначено лише для лінивого датафрейму, тоді як у таблиці 5.6 — лише для датафрейму. Збережено так, як у книзі.

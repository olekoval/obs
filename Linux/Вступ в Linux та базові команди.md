### Створення системи папок
```
mkdir -p ~/projects/web/my-app
```

- `~` — ваша домашня директорія (`/home/username`).
    
- `-p` — дозволяє створити всю потрібну ланцюжок папок (`projects` -> `web` -> `my-app`), навіть якщо жодної з них ще не існує.

###  Клонувати у поточну папку (без створення додаткової підпапки)

Якщо ви вже перебуваєте всередині папки `my-app` і хочете завантажити файли проєкту безпосередньо в неї (крапка в кінці вказує на поточну директорію):

Bash

```
git clone https://github.com/username/repository.git .
```

> **Зверніть увагу:** Поточна папка має бути порожньою.

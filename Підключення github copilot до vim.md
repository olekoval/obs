### Встатовленне ПО
- Node.js v20.20.2
- Vim v9.1.697
### Встановлення плагіна
```bash
git clone --depth=1 https://github.com/github/copilot.vim.git ~/.vim/pack/github/start/copilot.vim
```
### Налаштування `.vimrc` для Python
```
" Увімкнення підсвітки синтаксису
syntax on

" Увімкнення виявлення типу файлів, завантаження плагінів та відступів для них
filetype plugin indent on
```
### Авторизація Copilot у Vim
Тепер потрібно зв'язати встановлений плагін з вашим обліковим записом GitHub.

1. Запустіть Vim у терміналі:

```
vim
```

1. Увійдіть у командний режим (натисніть `Esc`, потім `:`), введіть команду налаштування та натисніть `Enter`:

```
:Copilot setup
```

1. Vim виведе повідомлення з **8-значним кодом пристрою** (Device code) та посиланням на сторінку активації (зазвичай це `https://github.com/login/device`).
2. Скопіюйте цей код, перейдіть за посиланням у браузері вашої Windows 11, вставте код та натисніть **Authorize GitHub Copilot**.
3. Поверніться в термінал із Vim — ви побачите повідомлення про успішну авторизацію. Тепер можете закрити Vim командою `:q!`.

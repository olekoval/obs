### Якщо в папці вже зроблено `git init`

Якщо ви вже ініціалізували порожній Git-репозиторій у цій папці й хочете «підтягнути» туди проєкт з GitHub:

1. **Відкрийте термінал** у цій папці.
    
2. **Зв'яжіть локальну папку з віддаленим репозиторієм** на GitHub (назвемо його стандартно — `origin`):
```bash
git remote add origin <URL_репозиторію>
```
3. **Перевірте назву головної гілки** на GitHub (зазвичай це `main` або `master`).
    
4. **Завантажте та об'єднайте дані:**
```shell
git pull origin main
```
(Замініть `main` на `master`, якщо на GitHub головна гілка називається по-старому).

Папка all_data істить всі дані надіслані Дудник С.В., це дані за 4 місяці за різними сервісами 9 пакету.

Даних багато, тому для їх опрацювання я використовував можливість їх стистення (`.parquet`).
Оскільки дані вантажились з оригінальних ексень файлів то було проведено зміну назв колонок, в файлі `tables_columns.xlsx` зазначено всі відповідники до оригінальних позначень.

Оскільки низка колонок містила інформацію про коди інтервенцій, консультацій та професій лікарів і тягнуло память то я 
залишав лишень коди, їх розшифровка міститься на аркушах в файлах `dictianaries/*_dictionaries`

Було визначено завдання витягнути дані за окремими закладами (лабораторї CSD, Synevo) за всіма напрямками сервісів (лабораторні дослідження,
процедурні ...) для цього є файл `extract_data_dy_edrpou.py`.

Вже витягнуті дані за лабораторіями знаходяться в відповідних дерикторіях `csd` та `synevo`, щодо їх подальшої обробки,
зведення чи групування поки завдань не було.

Папка `агрегування`, це чисто пробний запит на агрегацію даних по дослідженням за лабораторіями - чітку структуру ніхто не визначав, чисто моє бачення.

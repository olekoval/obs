

# 🗄️ Наповнення бази даних початковими даними (Seed)

## 📌 Крок 1. Створення `seed.py`

Створи файл `seed.py` в корені проєкту:

Python

```python
import click
from flask.cli import with_appcontext
from models import db, Weight, Exercise

def register_seed_commands(app):
    @app.cli.command("seed-db")
    @with_appcontext
    def seed_db():
        click.echo("🚀 Заповнення довідників...")

        # 1. Ваги
        weights = [
            {"tools": "Власна вага", "weight_value": 0.0},
            {"tools": "Гиря чавунна", "weight_value": 16.0},
            {"tools": "Гиря чавунна", "weight_value": 24.0},
            {"tools": "Гиря чавунна", "weight_value": 32.0},
            {"tools": "Гиря змагальна", "weight_value": 20.0},
            {"tools": "Гиря змагальна", "weight_value": 28.0},
        ]
        for w in weights:
            if not db.session.scalar(db.select(Weight).where(Weight.tools == w["tools"], Weight.weight_value == w["weight_value"])):
                db.session.add(Weight(tools=w["tools"], weight_value=w["weight_value"]))

        # 2. Вправи
        exercises = [
            {"name_en": "Kettlebell Swing", "name_ua": "Махи з гирею", "description": "Павел Цацулін (Hardstyle / Strong Endurance)."},
            {"name_en": "Turkish Get-Up (TGU)", "name_ua": "Турецький підйом", "description": "Стабільність та контроль плечового поясу."},
            {"name_en": "Kettlebell Snatch", "name_ua": "Ривок гирі", "description": "Тест на силову витривалість заднього ланцюга."},
            {"name_en": "Kettlebell Clean & Jerk", "name_ua": "Поштовх за довгим циклом", "description": "Максимальний системний об'єм роботи."},
            {"name_en": "Running (Easy Pace)", "name_ua": "Біг (Легкий темп)", "description": "Аеробна база E-pace за Джеком Деніелсом."},
            {"name_en": "Running (Intervals)", "name_ua": "Біг (Інтервали)", "description": "Робота на рівні МСК (I-pace) за Деніелсом."}
        ]
        for ex in exercises:
            if not db.session.scalar(db.select(Exercise).where((Exercise.name_en == ex["name_en"]) | (Exercise.name_ua == ex["name_ua"]))):
                db.session.add(Exercise(name_en=ex["name_en"], name_ua=ex["name_ua"], description=ex["description"]))

        db.session.commit()
        click.echo("✅ Готово!")
```

## 💻 Крок 3. Запуск у терміналі

Виконай послідовно:

Bash

```shall
flask db upgrade
flask seed-db
```

### 🛠️ Пам'ятка: Якщо додалося нове поле (наприклад, `difficulty`)

1. Онови модель у `models.py`.
    
2. Виконай `flask db migrate -m "..."` та `flask db upgrade`.
    
3. У `seed.py` допиши поле в масив та в конструктор: `difficulty=ex.get("difficulty")`.
    
4. _Якщо поле впливає на унікальність_ — додай його в перевірку `.where()`.

**CLI команди** (від англ. **Command Line Interface** — _інтерфейс командного рядка_) — это спосіб керування комп'ютером, програмами або сервером за допомогою введення текстових рядків (команд) з клавіатури в спеціальне вікно (термінал, консоль або командний рядок).

На відміну від **GUI** (Graphical User Interface), де ти взаємодієш із програмою через графічні елементи — клікаєш мишкою по кнопках, меню та іконках — у **CLI** все робиться виключно текстом.

### Проста аналогія

- **GUI (Графічний інтерфейс):** Ти приходиш у ресторан, перед тобою меню з картинками. Ти просто тицяєш пальцем у страву "Борщ", і офіціант її приносить.
    
- **CLI (Командний рядок):** Ти заходиш на кухню і чітко кажеш кухарю: `приготувати --страва="борщ" --порція=велика`. Кухар виконує точний текстовий наказ.
    

### З чого складається CLI команда?

Зазвичай структура будь-якої CLI команди виглядає так:

Bash

```
назва_програми  дія/підкоманда  --параметри (флаги)
```

Розберемо на прикладі команд з твого Flask-проєкту:

1. `flask db upgrade`
    
    - `flask` — запуск головної програми.
        
    - `db` — підкоманда (ми кажемо Flask, що хочемо працювати саме з базою даних).
        
    - `upgrade` — конкретна дія (застосувати міграції, оновити структуру).
        
2. `flask seed-db`
    
    - `flask` — головна програма.
        
    - `seed-db` — створена тобою кастомна команда, яка запускає функцію наповнення таблиць даними.
        

### Навіщо розробники використовують CLI замість звичайних програм?

1. **Швидкість та автоматизація:** Набрати команду на клавіатурі часто значно швидше, ніж відкривати програму, чекати завантаження графіки, шукати потрібну кнопку в меню і клікати на неї. Окрім того, текстові команди можна збирати в скрипти (автоматизувати роботу).
    
2. **Економія ресурсів:** Графічний інтерфейс (вікна, анімації, іконки) споживає багато оперативної пам'яті та ресурсів процесора. CLI працює миттєво і "важить" мінімум.
    
3. **Робота з серверами:** Більшість серверів в інтернеті (наприклад, де буде крутитися твій сайт) взагалі не мають монітора чи графічного інтерфейсу. Доступ до них відбувається віддалено через термінал, і керувати ними можна **тільки** за допомогою CLI команд.
    
4. **Розширюваність (як у твоєму випадку):** Фреймворки на кшталт Flask дозволяють розробнику легко створювати _власні_ CLI команди (як-от `seed-db`), щоб автоматизувати рутинні процеси розробки прямо з термінала VS Code.

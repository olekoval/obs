### 📝 Опис задачі

Необхідно згрупувати дані з Excel за стовпчиком `АДСГ` та порахувати кількість різних типів коефіцієнтів, які містяться всередині стовпчика `Коефіцієнт` у форматі JSON-рядків.

Додатково потрібно розрахувати комбіновані метрики (одночасна присутність коефіцієнтів та специфічна тривалість лікування) загалом по датафрейму та окремо для дітей (вік < 18 років), після чого об'єднати результати.

### 🛠 Ключові технічні рішення

1. **Парсинг JSON:** Використано комбінацію `json.loads` та `.apply(pd.Series)` для розгортання ключів JSON у повноцінні стовпчики.
    
2. **Агрегація базових коефіцієнтів:** Використано метод `.count()`, який рахує лише заповнені комірки (`non-NaN`), що дозволяє дізнатися, скільки разів зустрівся кожен тип коефіцієнта.
    
3. **Обчислення бінарних умов (AND / тривалість):** Створено стовпчики-індикатори із замінаю логічних умов на цифри `1` або `0` через `.astype(int)`. Для них під час групування застосовується функція `sum()`.
    
4. **Динамічний `agg_dict`:** Написано генератор словника для методу `.agg()`, який автоматично виставляє `"sum"` для колонок-маркерів та `"count"` для стандартних коефіцієнтів.
    
5. **Розділення потоків та Мердж:** Створено універсальну функцію `calculate_metrics()`. Розрахунок проведено двічі (для всіх та для дітей). До колонок дитячого датафрейму додано суфікс `" Діти"`, після чого зроблено `pd.merge(..., how='left', on='АДСГ')`.
    

### 💻 Фінальний та перевірений код

Python

```python
import json
import pandas as pd

# 1. Зчитування даних
df_26 = pd.read_excel(
    "./data/packet_3_2026.xlsx",
    usecols=[
        "АДСГ",
        "Коефіцієнт",
        "Вік пацієнта в роках на момент створення ЕМЗ",
        "Тривалість лікування, в днях",
        "Включення медичного запису до статистики",
    ],
)


# --- ФУНКЦІЯ ДЛЯ РОЗРАХУНКУ МЕТРИК ---
def calculate_metrics(df_source):
    # Розгортаємо JSON коефіцієнтів у стовпчики
    df_coefs = df_source["Коефіцієнт"].apply(json.loads).apply(pd.Series)

    # Додаємо умови для комбінацій коефіцієнтів
    if (
        "full_coef_child" in df_coefs.columns
        and "coef_p3_p4_18minus" in df_coefs.columns
    ):
        df_coefs["child_AND_18minus"] = (
            df_coefs["full_coef_child"].notna()
            & df_coefs["coef_p3_p4_18minus"].notna()
        ).astype(int)
    else:
        df_coefs["child_AND_18minus"] = 0

    if "vit_days" in df_coefs.columns and "dializ_days" in df_coefs.columns:
        df_coefs["vit_AND_dializ_days"] = (
            df_coefs["vit_days"].notna() & df_coefs["dializ_days"].notna()
        ).astype(int)
    else:
        df_coefs["vit_AND_dializ_days"] = 0

    # Додаємо умови для тривалості лікування (0 та 1 днів)
    df_coefs["duration_0_days"] = (
        df_source["Тривалість лікування, в днях"] == 0
    ).astype(int)
    df_coefs["duration_1_day"] = (
        df_source["Тривалість лікування, в днях"] == 1
    ).astype(int)

    # Об'єднуємо з АДСГ
    df_merged = pd.concat([df_source["АДСГ"], df_coefs], axis=1)

    # Динамічно формуємо інструкції для агрегації (sum для індикаторів, count для решти)
    agg_dict = {
        col: ("sum" if ("AND" in col or "duration" in col) else "count")
        for col in df_merged.columns
        if col != "АДСГ"
    }

    # Групуємо та повертаємо результат
    return df_merged.groupby("АДСГ", as_index=False).agg(agg_dict)


# --- ОСНОВНИЙ БЛОК РОЗРАХУНКІВ ---

# Розрахунок 1: Всі записи
df_26_filter = df_26[
    df_26["Включення медичного запису до статистики"] == "Так"
].copy()
final_df_all = calculate_metrics(df_26_filter)

# Розрахунок 2: Суто діти (< 18 років)
df_26_child_filter = df_26[
    (df_26["Включення медичного запису до статистики"] == "Так")
    & (df_26["Вік пацієнта в роках на момент створення ЕМЗ"] < 18)
].copy()
final_df_child = calculate_metrics(df_26_child_filter)

# Перейменування дитячих колонок (додаємо " Діти")
final_df_child = final_df_child.rename(
    columns={
        col: f"{col} Діти" for col in final_df_child.columns if col != "АДСГ"
    }
)

# Об'єднання результатів (Left Join) та заповнення пустих значень нулями
final_df = pd.merge(final_df_all, final_df_child, on="АДСГ", how="left")
final_df = final_df.fillna(0)

# Перейменування фінальних розрахункових колонок під бізнес-вимоги
final_df = final_df.rename(
    columns={
        "child_AND_18minus": "одночасно full_coef_child та coef_p3_p4_18minus",
        "vit_AND_dializ_days": "Одночасно vit_days та dializ_days",
        "child_AND_18minus  Діти": "одночасно full_coef_child та coef_p3_p4_18minus Діти",
        "vit_AND_dializ_days  Діти": "Одночасно vit_days та dializ_days Діти",
    }
)
```

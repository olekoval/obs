
**Контекст:** Розрахунок кількості дітей віком 0–5 років (включно), які мають декларації з сімейним лікарем, у розрізі областей (на основі адреси закладу з JSON) та ЄДРПОУ за 2023, 2024 та 2025 роки.
**СУБД:** PostgreSQL (НСЗУ Дата-платформа)
**Методологія:** Динамічний розрахунок віку на зріз кінця кожного року + гнучкий облік історичних статусів (`SCD2` / `snapshot` логіка).

---

## 1. Розуміння завдання та метрики

1. **Цільова аудиторія:** Діти віком **від 0 до 5 років включно** (тобто `age BETWEEN 0 AND 5`).
2. **Динамічний вік (Важливо!):** Вік дитини розраховується строго на дату зрізу конкретного звітного року (31 грудня), а не на поточну дату розрахунку. Пацієнт, який у 2023 році був у віці 5 років, у 2025 році вже має 7 років і не повинен враховуватися.
3. **Область реєстрації:** Визначається через першоджерело — поле-масив `addresses` (тип даних `json`/ `jsonb`) у таблиці юридичних осіб (`core.dim_rpt_legal_entities`), витягуючи ключ `"area"`.
4. **Тип зв'язку (`LEFT JOIN`):** Використовується для запобігання втрати декларацій закладами, які на поточний момент могли бути реорганізовані, закриті або відсутні в поточному мастер-довіднику.

---

## 2. Бізнес-логіка та обробка історичних статусів

* **Проблема початкового підходу:** Жорсткий фільтр `d.status = 'active'` у блоці `WHERE` відсікав історичні декларації, які зараз мають статус `terminated` (розірвані), але у 2023 чи 2024 роках були чинними. Це призводило до штучного зміщення даних у категорію "Не вказано" або повної втрати рядків.
* **Рішення:** Перенесення перевірки життєвого циклу декларації безпосередньо всередину аналітичного вікна кожного року за допомогою умовного агрегування (`Conditional Aggregation`):
  * Декларація вважається дійсною на кінець року, якщо: `start_date <= 'YYYY-12-31' AND (status = 'active' OR end_date > 'YYYY-12-31')`.

## 3. Фінальний SQL-скрипт для Obsidian

- ### 3.1. Варіант 1 ---------------------------------------------------------
	Резу.льтат коду
	
	
	```sql
	WITH parsed_data AS (
	    SELECT 
	        -- Якщо закладу немає в поточному довіднику, виводимо технічний маркер
	        COALESCE(le.edrpou, 'Невідомий ЄДРПОУ') AS edrpou,
	        
	        -- Парсимо область з першого елемента масиву JSON поля addresses. 
	        -- Оператор ->0 бере перший елемент, ->> дістає текстове значення ключа 'area'
	        COALESCE(le.addresses->0->>'area', 'Не вказано') AS region,
	        
	        p.birth_date,
	        d.start_date,
	        d.end_date,
	        d.status,
	        
	        -- Динамічний розрахунок повних років дитини на кінець кожного звітного року
	        EXTRACT(YEAR FROM AGE('2023-12-31'::date, p.birth_date)) AS age_2023,
	        EXTRACT(YEAR FROM AGE('2024-12-31'::date, p.birth_date)) AS age_2024,
	        EXTRACT(YEAR FROM AGE('2025-12-31'::date, p.birth_date)) AS age_2025
	    FROM core.dim_rpt_declarations d
	    INNER JOIN core.dim_rpt_persons p 
	        ON d.person_id = p.id AND p.is_current = 'Y'
	    LEFT JOIN core.dim_rpt_legal_entities le 
	        ON d.legal_entity_id = le.id AND le.is_current = 'Y'
	    WHERE d.is_current = 'Y'
	      AND d.status IN ('active', 'terminated')
	)
	SELECT 
	    edrpou AS "ЄДРПОУ",
	    region AS "Область (з JSON addresses)",
	    
	    -- Кількість дітей 0-5 років на кінець 2023 року
	    COUNT(CASE 
	        WHEN start_date <= '2023-12-31' 
	         AND (status = 'active' OR end_date > '2023-12-31')
	         AND age_2023 BETWEEN 0 AND 5 
	        THEN 1 
	    END) AS "2023 рік",
	    
	    -- Кількість дітей 0-5 років на кінець 2024 року
	    COUNT(CASE 
	        WHEN start_date <= '2024-12-31' 
	         AND (status = 'active' OR end_date > '2024-12-31')
	         AND age_2024 BETWEEN 0 AND 5 
	        THEN 1 
	    END) AS "2024 рік",
	    
	    -- Кількість дітей 0-5 років на кінець 2025 року
	    COUNT(CASE 
	        WHEN start_date <= '2025-12-31' 
	         AND (status = 'active' OR end_date > '2025-12-31')
	         AND age_2025 BETWEEN 0 AND 5 
	        THEN 1 
	    END) AS "2025 рік"
	
	FROM parsed_data
	GROUP BY edrpou, region
	HAVING 
	    -- Оптимізація вибірки: залишаємо лише заклади, де є хоча б одна дитина у вказаних періодах
	    COUNT(CASE WHEN start_date <= '2023-12-31' AND (status = 'active' OR end_date > '2023-12-31' ) AND age_2023 BETWEEN 0 AND 5 THEN 1 END) > 0 OR
	    COUNT(CASE WHEN start_date <= '2024-12-31' AND (status = 'active' OR end_date > '2024-12-31' ) AND age_2024 BETWEEN 0 AND 5 THEN 1 END) > 0 OR
	    COUNT(CASE WHEN start_date <= '2025-12-31' AND (status = 'active' OR end_date > '2025-12-31' ) AND age_2025 BETWEEN 0 AND 5 THEN 1 END) > 0
	ORDER BY region ASC, edrpou ASC;
	```
	- ### 3.2. Варіант 2 ------------------------------------------------------
```sql
WITH parsed_data AS (
    SELECT 
        COALESCE(le.edrpou, 'Невідомий ЄДРПОУ') AS edrpou,
        COALESCE(le.addresses->0->>'area', 'Не вказано') AS region,
        
        p.id AS person_id,
        p.birth_date,
        d.start_date,
        d.end_date,
        d.status,
        
        -- Динамічний вік на кінець кожного року
        EXTRACT(YEAR FROM AGE('2023-12-31'::date, p.birth_date)) AS age_2023,
        EXTRACT(YEAR FROM AGE('2024-12-31'::date, p.birth_date)) AS age_2024,
        EXTRACT(YEAR FROM AGE('2025-12-31'::date, p.birth_date)) AS age_2025
    FROM core.dim_rpt_declarations d
    INNER JOIN core.dim_rpt_persons p 
        ON d.person_id = p.id AND p.is_current = 'Y'
    LEFT JOIN core.dim_rpt_legal_entities le 
        ON d.legal_entity_id = le.id AND le.is_current = 'Y'
    WHERE d.is_current = 'Y'
      AND d.status IN ('active', 'terminated')
),
aggregated_counts AS (
    SELECT 
        edrpou,
        region,
        
        -- Кількість унікальних дітей 0-5 років на кінець 2023 року
        COUNT(DISTINCT CASE 
            WHEN birth_date <= '2023-12-31'  -- Дитина вже народилася
             AND start_date <= '2023-12-31'  -- Декларація вже була створена
             AND (
                 status = 'active'           -- Або вона активна зараз
                 OR end_date > '2023-12-31'  -- Або її закрили вже ПІСЛЯ дати зрізу
             )
             AND age_2023 BETWEEN 0 AND 5 
            THEN person_id                   -- Схлопуємо всі записи дитини в 1 унікальну
        END) AS "2023 рік",
        
        -- Кількість унікальних дітей 0-5 років на кінець 2024 року
        COUNT(DISTINCT CASE 
            WHEN birth_date <= '2024-12-31'
             AND start_date <= '2024-12-31'
             AND (
                 status = 'active'
                 OR end_date > '2024-12-31'
             )
             AND age_2024 BETWEEN 0 AND 5 
            THEN person_id
        END) AS "2024 рік",
        
        -- Кількість унікальних дітей 0-5 років на кінець 2025 року
        COUNT(DISTINCT CASE 
            WHEN birth_date <= '2025-12-31'
             AND start_date <= '2025-12-31'
             AND (
                 status = 'active'
                 OR end_date > '2025-12-31'
             )
             AND age_2025 BETWEEN 0 AND 5 
            THEN person_id
        END) AS "2025 рік"
    FROM parsed_data
    GROUP BY edrpou, region
)
SELECT 
    edrpou AS "ЄДРПОУ",
    region AS "Область (з JSON addresses)",
    "2023 рік",
    "2024 рік",
    "2025 рік"
FROM aggregated_counts
WHERE "2023 рік" > 0 
   OR "2024 рік" > 0 
   OR "2025 рік" > 0
ORDER BY region ASC, edrpou ASC;
```

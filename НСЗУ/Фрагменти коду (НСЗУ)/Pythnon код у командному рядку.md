### Як працює прапорець `-c` (Execute Code)

Зазвичай, коли ми пишемо `python script.py`, ми просимо Python запустити цілий файл.

Але прапорець **`-c` (скорочено від _command_)** дозволяє передати Python-код прямо в термінал як звичайний рядок, не створюючи для цього окремих тимчасових файлів.

Синтаксис виглядає так:

Bash

```bash
python -c "твій код на Python"
```

### Розбір нашої команди по кроках

Ми передали всередину лапок два рядки коду, розділивши їх крапкою з комою `;` (в Python так можна робити, якщо код записується в один рядок):

1. **`import data_utils;`**
    
    Python заходить у твою поточну папку, знаходить файл `data_utils.py` і починає його виконувати від початку до кінця. Оскільки в твоєму скрипті зчитування Excel-файлів та створення великого датафрейму `dff` написані на рівні самого модуля (не всередині функцій), вони виконуються автоматично в момент імпорту.
    
2. **`print(..., data_utils.dff.shape)`**
    
    Після імпорту ми звертаємося до глобальної змінної `dff`, яка тепер живе всередині імпортованого модуля. Атрибут `.shape` у pandas повертає кортеж (tuple) виду `(кількість_рядків, кількість_колонок)`.
    

### Як ти можеш використовувати це в майбутньому (Приклади)

Цей підхід ідеальний для швидких "санітарних перевірок" (smoke tests) коду без запуску всього Flask-додатка.

- **Швидко протестувати роботу конкретної функції з твого скрипта:**
    
    Ти можеш прямо в терміналі викликати, наприклад, пошук правила і подивитися, що він повертає:
    
    Bash
    
    ```bash
    python -c "import data_utils; print(data_utils.search_rules_by_code('10331-7'))"
    ```
    
- **Перевірити версію бібліотеки в поточному середовищі (Poetry/Venv):**
    
    Bash
    
    ```bash
    python -c "import pandas as pd; print(pd.__version__)"
    ```
    
- **Перевірити, чи доступна база даних (наприклад, Postgres), перед стартом роботи:**
    
    Bash
    
    ```bash
    python -c "import psycopg2; print('Драйвер встановлено!')"
    ```

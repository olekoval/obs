# 📊 PMG Events Data Pipeline (Polars + ADBC)

Інструмент для автоматизованого вивантаження, збагачення та аналізу даних щодо медичних подій (Events) за Програмою медичних гарантій (ПМГ).

Скрипт отримує дані з аналітичних та довідникових таблиць бази даних PostgreSQL/DWH через високопродуктивний двигун **ADBC**, розгортає списки додаткових діагнозів та інтервенцій, здійснює їхню розшифровку за офіційними довідниками та експортує підсумкові вибірки у формати **Parquet** та **Excel**.

---

## 🛠 Технологічний стек

* **Python** 3.10+
* **Polars** (High-performance DataFrame library)
* **ADBC Driver** (Arrow Database Connectivity for PostgreSQL)
* **XlsxWriter** (для заповнення Excel-звітів)
* **python-dotenv** (управління конфігурацією та секретами)

---

## ⚙️ Попередні вимоги та встановлення

### 1. Клонування / підготовка проекту
Переконайся, що у тебе встановлено Python 3.10 або новішої версії.

### 2. Встановлення залежностей

Якщо використовується **Pip**:
```bash
pip install polars adbc-driver-postgresql python-dotenv xlsxwriter
````

Якщо використовується **Poetry**:

Bash

```
poetry add polars adbc-driver-postgresql python-dotenv xlsxwriter
```

### 3. Конфігурація середовища (`.env`)

Створи у корені проекту файл `.env` із параметром підключення до бази даних:

Фрагмент коду

```
DB_URL="postgresql://user:password@hostname:5432/dbname"
```

## 📁 Структура вихідних файлів

Результати виконання зберігаються у директорії `./data/`:

- **`output_file.parquet`** — Основний аналітичний файл у високостисненому бінарному форматі. Зберігає оригінальні типи даних (у тому числі `Binary` UUID).
    
- **`output_file.xlsx`** — Звіт для аналізу в Microsoft Excel. Усі бінарні ідентифікатори автоматично перетворені у читабельний HEX-формат (`bin.encode("hex")`), а колоночні масиви видалені для уникнення помилок сумісності.

## 🛡 Обробка винятків та оптимізації

1. **Захист від Binary UUID (`invalid utf8`):** При записі в Excel усі бінарні поля автоматично переганяються в шістнадцяткову строку (`HEX`), що запобігає падінню двигуна `xlsxwriter`.
    
2. **Ліміт Excel:** Якщо кількість рядків перевищує `1,048,575`, скрипт автоматично виведе попередження та збереже дані **тільки** у Parquet, запобігаючи аварійному завершенню через обмеження XLSX.
    
3. **Обробка порожніх значень:** Використання `.fill_null("")` та `empty_as_null=True` гарантує відсутність втрати даних при з'єднанні рядків із відсутніми описами.

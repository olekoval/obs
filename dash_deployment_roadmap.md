# 🗺️ План розгортання Dash-додатка на сервері Debian 12

Цей документ містить покрокову карту дій для розгортання вебдодатка Dash із GitHub на локальному сервері Debian 12 із забезпеченням зовнішнього доступу.

---

## 📌 Загальний огляд етапів

```
[ GitHub Repo ] ──> [ 1. Підготовка & Git ] ──> [ 2. WSGI (Gunicorn) ] ──> [ 3. Автозапуск (systemd) ] ──> [ 4. Reverse Proxy (Nginx) & Доступ ]
```

---

## 🚀 Деталізація кроків

### Крок 1: Підготовка середовища та завантаження коду
* **Встановлення системних залежностей:** Python 3, `pip`, `venv`, `git`.
* **Клонування репозиторію:** Завантаження коду проєкту з GitHub на сервер.
* **Віртуальне середовище:** Створення та активація ізольованого середовища (`python3 -m venv venv` або `poetry`).
* **Встановлення пакетів:** Встановлення залежностей проєкту (`requirements.txt` / `pyproject.toml`).

### Крок 2: Налаштування Production WSGI-сервера (Gunicorn)
* **Перевірка роботи:** Тестовий запуск додатка через Python.
* **Інтеграція Gunicorn:** Підключення production-сервера HTTP WSGI для Flask/Dash (`gunicorn app:server`).
* **Конфігурація воркерів:** Визначення оптимальної кількості процесів для продуктивності.

### Крок 3: Фоновий запуск та автозапуск через systemd
* **Створення сервісу:** Написання конфігураційного файлу `/etc/systemd/system/dash-app.service`.
* **Автономність:** Забезпечення роботи додатка у фоновому режимі без активної SSH-сесії.
* **Автозапуск:** Налаштування автоматичного старту сервісу після перезавантаження сервера.

### Крок 4: Вебсервер (Nginx) та налаштування зовнішнього доступу
* **Nginx Reverse Proxy:** Встановлення та перенаправлення трафіку з порту 80 (HTTP) на локальний порт Gunicorn.
* **Брандмауер UFW:** Відкриття необхідних портів (80 / 443) для вебтрафіку.
* **Зовнішній доступ:**
  * *Локальна мережа:* Доступ за IP-адресою сервера (`http://192.168.0.193`).
  * *Інтернет (опціонально):* Налаштування Port Forwarding на роутері, Cloudflare Tunnel або HTTPS через Let's Encrypt / Certbot.

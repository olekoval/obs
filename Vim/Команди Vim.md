## <span style='color: yellow'>Комбіновані команди вставки</span>

| **Команда Vim** | **Еквівалентна дія ** | **Опис**                                                                         |
| --------------- | --------------------- | -------------------------------------------------------------------------------- |
| **C**           | `c$`                  | Змінити текст від курсора до кінця рядка                                         |
| **s**           | `cl`                  | Видалити символ під курсором і перейти в режим вставки (змінити символ)          |
| **S**           | `^C`                  | Очистити весь рядок і перейти в режим вставки                                    |
| **I**           | `^i`                  | Перейти на початок рядка (до першого непустого символу) і ввійти в режим вставки |
| **A**           | `$a`                  | Перейти в кінець рядка і ввійти в режим вставки                                  |
| **o**           | `A<CR>`               | Створити новий рядок нижче поточного та перейти в режим вставки                  |
| **O**           | `ko`                  | Створити новий рядок вище поточного та перейти в режим вставки                   |
##
| **Категорія / Дія**                  | **Команди**                                        | **Що робить**                                                                                                   |
| ------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Пошук символу в рядку (вперед)**   | `f{char}` / `t{char}`<br><br>  <br><br>`;` / `,`   | Знайти символ на/до вказаного символу вперед. `;` — повторити пошук, `,` — у зворотному напрямку.               |
| **Пошук символу в рядку (назад)**    | `F{char}` / `T{char}`<br><br>  <br><br>`;` / `,`   | Знайти символ на/до вказаного символу назад. `;` — повторити у тому ж напрямку, `,` — у зворотному.             |
| **Пошук збігу в документі (вперед)** | `/pattern<CR>`<br><br>  <br><br>`n` / `N`          | Знайти шаблон вперед по тексту. `n` — наступний збіг, `N` — попередній.                                         |
| **Пошук збігу в документі (назад)**  | `?pattern<CR>`<br><br>  <br><br>`n` / `N`          | Знайти шаблон назад по тексту. `n` — наступний збіг у напрямку пошуку, `N` — у протилежному.                    |
| **Заміна (підстановка) у рядку**     | `:s/target/replacement`<br><br>  <br><br>`&` / `u` | Замінити `target` на `replacement` у поточному рядку. `&` — повторити останню заміну, `u` — скасувати (`undo`). |
| **Макроси (послідовності змін)**     | `qx` ... `q`<br><br>  <br><br>`@x` / `u`           | Записати послідовність команд у макрос `x`. Викликати макрос через `@x`. `u` — скасувати дію.                   |
